## ✨ Features

### 🎨 Design & UI/UX

- **Modern & Clean Design**: Professional business aesthetic with contemporary styling
- **Fully Responsive**: Optimized for all devices (desktop, tablet, mobile)
- **Dark/Light Mode**: Built-in theme switching capabilities
- **Smooth Animations**: AOS (Animate On Scroll) integration for engaging user experience
- **Accessibility**: WCAG compliant with proper semantic HTML structure

### 📱 Pages & Components

- **Homepage**: Hero section, services showcase, testimonials, portfolio
- **About Us**: Company information, team members, mission & vision
- **Services**: Detailed service offerings with pricing
- **Portfolio/Projects**: Project showcase with filtering capabilities
- **Blog**: Article listings and detailed blog posts
- **Contact**: Contact forms and location information
- **Authentication**: Sign-in and sign-up pages
- **Legal Pages**: Privacy policy, terms & conditions
- **404 Error Page**: Custom error handling

### 🛠 Technical Features

- **Bootstrap 5.3+**: Latest Bootstrap framework with modern components
- **SCSS/CSS**: Modular styling with custom variables and utilities
- **JavaScript**: Interactive components and smooth functionality
- **Owl Carousel**: Touch-enabled carousel for testimonials and portfolios
- **Iconify**: Modern icon system with extensive icon library
- **SEO Optimized**: Meta tags, structured data, and performance optimized

## 📦 Installation

### Prerequisites

- Modern web browser
- Local development server (optional, for development)

### Quick Start

1. **Clone the repository**

   ```bash
   git clone https://github.com/themewagon/Decor-s-Digital.git
   cd Decor-s-Digital
   ```

2. **Open in your browser**
   - Navigate to the `html/` directory
   - Open `index.html` in your web browser
   - Or serve locally using a development server

### Development Setup

1. **Install dependencies** (if using a build process)

   ```bash
   npm install
   # or
   yarn install
   ```

2. **Start development server**
   ```bash
   npm start
   # or
   yarn start
   ```

## 🎨 Customization

### Colors & Branding

- Primary colors are defined in `assets/scss/variables/_variables.scss`
- Logo files are located in `assets/images/logos/`
- Customize brand colors and typography in the SCSS variables

### Content Management

- Update content directly in HTML files
- Replace images in `assets/images/` directory
- Modify text content in respective HTML files

### Styling

- Main stylesheet: `assets/css/styles.css`
- SCSS source files: `assets/scss/`
- Custom utilities: `assets/scss/utilities/`
